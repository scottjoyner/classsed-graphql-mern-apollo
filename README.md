# GraphQL / MERN / Apollo Class Project

An educational Node.js project experimenting with GraphQL, Apollo Server, and MongoDB through Mongoose.

## Dependencies

The root `package.json` lists `apollo-server` 2.x, `graphql` 14.x, and `mongoose` 5.x. These are legacy major versions; evaluate their compatibility and security before starting a network-facing process.

## Getting started

```bash
npm install
```

The repository does not currently define a working test script: `npm test` is a placeholder that exits with an error. Locate the application entry point and supply a MongoDB connection string using your own local or test configuration before attempting to run it.
